# TikTok

## 支持的链接

使用标准直播链接：

`https://www.tiktok.com/@用户名/live`

录制器会将用户名作为频道 ID，因此主播下播后仍可继续自动监听。

:::tip
请确保你的网络可以正常访问tiktok，或者去 `设置/直播录制/tiktok/代理` 选项中进行设置
:::

## 直播流

- 画质使用 TikTok 原生标识：

| 画质   | 值       |
| ------ | -------- |
| 原画   | `origin` |
| 蓝光   | `uhd`    |
| 超清   | `hd`     |
| 高清   | `sd`     |
| 标清   | `ld`     |
| 音频流 | `ao`     |

- 流格式支持优先或强制使用 FLV、HLS。
- 流编码支持 AVC 和 HEVC；强制编码时，如果 TikTok 没有返回对应编码，录制不会自动回退。

## 弹幕

当前版本暂不支持 TikTok 弹幕录制。
